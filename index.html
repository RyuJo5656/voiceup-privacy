VoiceUp 개인정보 처리방침

최종 수정일: 2026년 6월 14일

VoiceUp은 목소리를 크게 내기 어려운 분을 돕는 음성 보조 앱입니다. VoiceUp은 자체 서버를 운영하지 않으며, 어떤 개인정보도 외부 서버에 수집·저장하지 않습니다. 앱이 만드는 데이터(자주 쓰는 문장, 음성 일지 녹음 등)는 사용자 기기 안에만 저장됩니다.

권한 사용 안내

  • 마이크 — 작은 목소리를 녹음하여 크게 재생하거나, 음성을 문자로 인식하기 위해 사용합니다. 녹음 데이터는 기기 내에서 처리되며 앱이 외부로 전송·보관하지 않습니다.
  • 전화 상태 — 통화의 시작·종료를 감지해 통화 보조 버튼을 자동으로 표시/숨기기 위해서만 사용합니다. 전화번호나 통화 기록은 읽지 않습니다.
  • 접근성 서비스 — 통화 화면 위에 보조 버튼을 표시하기 위한 용도로만 사용합니다. 화면의 내용을 읽거나 수집하지 않습니다.

음성 인식 처리

"말하기" 기능의 음성-문자 변환은 사용자 기기의 시스템 음성 서비스(예: Google 음성 인식)에서 처리되며, 해당 서비스 제공자의 정책이 적용될 수 있습니다. 사용자가 별도로 네이버 Clova API 키를 설정한 경우에 한해, 인식·합성을 위해 음성/텍스트가 네이버 클라우드로 전송될 수 있습니다(선택 사항, 기본 비활성).

제3자 제공 · 광고 · 분석

VoiceUp은 광고를 표시하지 않으며, 분석 도구나 추적 SDK를 사용하지 않습니다. 사용자가 직접 Clova를 설정한 경우를 제외하고 데이터를 제3자에게 제공하지 않습니다.

아동

VoiceUp은 아동을 대상으로 하지 않습니다.

데이터 삭제

기기에 저장된 데이터는 앱을 삭제하면 함께 제거됩니다.

English summary. VoiceUp helps people who have difficulty speaking loudly. The app runs no server and collects/stores no personal data off-device; data it creates (saved phrases, voice journal recordings) stays only on your device. Microphone is used to record a soft voice for loud playback and speech-to-text (processed by your device's system speech service; optionally Naver Clova if you configure keys). Phone state is used only to detect call start/end to auto-show the assist button (no numbers or call logs are read). The accessibility service is used only to display a floating button and does not read screen content. No ads, no analytics, no tracking. Contact: gorchg83@gmail.com
